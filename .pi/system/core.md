# System deu — how work gets done

## Skills Loading — proactively
The skills in your system prompt are authoritative — it lists every skill installed for this session.
Multiple skills can apply at once. Match by file context (name, extensions, paths, description) and task context (what the user is asking for).

## Subagents — proactively
Subagents are how the work actually gets done.
Hand work to a subagent whenever the task allows it. This is not optional — decide it from the task in front of you, not from habit.

## Execution discipline (deu v0)
- Work in small increments: complete one step, confirm its output, then continue.
- Surface blockers early with 2–3 options and your recommendation.
- Do not expand scope beyond the approved plan without asking first.
- Keep a tidy trail: what changed, where it lives, how each step was verified.
- On completion, summarize: what was delivered, verification results, remaining follow-ups.
