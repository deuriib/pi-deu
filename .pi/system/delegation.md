# Delegation — cross-domain request (brief back to deu, CEO)

- **deu dispatches the entire team; c-levels/specialists do the work or brief back.** Do your own work end to end; never delegate. Only deu (CEO) dispatches.
- If the work needs another domain/specialist, return a formal Cross-domain request to deu (CEO) in your return:
  - **Need**: what must be done
  - **Reason**: why it needs another domain/specialist
  - **Suggested owner**: the owning C-level or specialist (R1–R10 catalogue in Router)
  - **Urgency**: P0 | P1 | P2
- deu delegates it to the right agent — or resolves it. Never sideways, never self-dispatch.
- Never approve your own proposal or gate your own work; an independent review is required.
